# Android Clínica SeCuide - Trabalho Acadêmico

## Descrição
Aplicativo Android desenvolvido como trabalho acadêmico, voltado para gestão de clínicas.  
O sistema permite que pacientes enviem mensagens aos médicos, e que os médicos respondam, acompanhem histórico e agendem consultas.  
Inclui funcionalidades de cadastro de usuários, agendamento de consultas, visualização de mensagens e status de respostas.

## Funcionalidades
- Cadastro de usuários (Pacientes e Médicos)  
- Login e autenticação  
- Envio e recebimento de mensagens entre pacientes e médicos  
- Visualização de histórico de mensagens  
- Agendamento de consultas  
- Lista de consultas com status, data, hora e local  
- Layout responsivo e com ícones/emojis para melhor usabilidade  

## Tecnologias Utilizadas
- Java  
- Android Studio  
- SQLite (banco de dados local para demonstração)  
- XML para layouts e UI  

## Telas
- **Tela de Login**: Entrada do usuário (email e senha)  
- **Tela de Cadastro**: Cadastro do usuário (email e senha, nome, tipo)  
- **Tela de Paciente**: Envio de mensagens, histórico de mensagens e agendamento de consultas  
- **Tela de Médico**: Visualização de pacientes, respostas a mensagens, gerenciamento de consultas  
- **Tela de Administrador**: Gerenciamento dos usuarios, gerenciamentro de mensagens, gerenciamento de consultas
